# 쓰레개똥

> **개똥은 치웠는데, 어디다 버리지?**

강아지 산책 중 배변봉투를 든 보호자가 **지금 위치에서 가장 가까운, 버릴 수 있을 가능성이 높은 쓰레기통**을 빠르게 찾도록 돕는 모바일 웹 지도 서비스입니다.

- 회원가입 없이 바로 사용
- 앱을 켜면 가장 적절한 후보와 도보 거리를 바로 표시
- 외부 지도 앱으로 길찾기 연결
- "버려도 되는지"는 확인된 정보만 표시하고, 확인되지 않은 곳은 정직하게 `확인 안 됨`으로 표시

## 서비스 지역

현재는 **서울 구로구 항동 생활권**에서 시작합니다.

- 중심: 푸른수목원 / 범위: 도보 최대 20분 (직선 약 1.5km)
- 산책 동선: 푸른수목원, 항동 하버라인, 항동 철길, 서울수목원현대홈타운스위트, 역곡역 주변
- 확장 계획: **항동 → 구로구 → 서울시**

## 기술 스택 (예정)

| 영역 | 기술 | 선택 이유 |
|---|---|---|
| 프론트엔드 | React + Vite + TypeScript | 자료가 많고 초보자도 유지보수하기 쉬움 |
| 스타일 | Tailwind CSS | CSS 파일 관리 없이 빠르게 UI 구성 |
| 지도 | OpenStreetMap + Leaflet | 가입·API 키 없이 바로 사용. 길찾기는 카카오맵 링크로 연결 |
| DB | Supabase (PostgreSQL) | 별도 서버 없이 DB·API 사용 |
| 배포 | Vercel | GitHub 연동 자동 배포, PR 미리보기 |
| 형태 | 모바일 웹 (PWA) | 앱스토어 없이 QR로 바로 사용 |

## 실행 방법

```bash
npm install
npm run dev
```

쓰레기통 등록 기능을 쓰려면 `.env.example`을 복사해 `.env`를 만들고 Supabase 값을 넣습니다. 서버 설정은 `supabase/setup.sql`.

- 컴퓨터: 브라우저에서 `http://localhost:5173`
- 휴대폰: 컴퓨터와 같은 Wi-Fi에 연결한 뒤, 터미널에 나오는 `Network: http://192.168.x.x:5173` 주소로 접속

현재는 홈 화면만 있습니다. 디자인 규칙은 [`docs/design.md`](docs/design.md)를 참고하세요.

API 키는 `.env` 파일에 넣으며, 저장소에는 절대 커밋하지 않습니다.

## 데이터 원칙 요약

- 반려견 배변봉투 투기 가능 여부(`pet_waste_status`)는 현장 근거를 확인하기 전까지 항상 `unknown`
- 일반 쓰레기통이라는 이유만으로 "버려도 된다"고 판단하지 않음
- 공용 공간의 쓰레기통만 등록
- 모든 데이터는 출처를 추적할 수 있게 기록
