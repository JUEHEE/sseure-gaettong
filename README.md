# 쓰레개똥

> **개똥은 치웠는데, 어디다 버리지?**

강아지 산책 중 배변봉투를 든 보호자가 **지금 위치에서 가장 가까운, 버릴 수 있을 가능성이 높은 쓰레기통**을 빠르게 찾도록 돕는 모바일 웹 지도 서비스입니다.

**👉 바로 써 보기: https://sseure-gaettong.vercel.app** (휴대폰에서 여는 것을 추천합니다)

- 회원가입 없이 바로 사용
- 앱을 켜면 가장 적절한 후보 1곳과 대안 2곳을 방향·거리·도보 시간과 함께 표시
- 카카오맵 도보 길찾기로 바로 연결
- 산책하다 발견한 쓰레기통을 사진과 현재 위치로 등록
- "버려도 되는지"는 확인된 정보만 표시하고, 확인되지 않은 곳은 정직하게 `확인 안 됨`으로 표시

## 지금 되는 것

| 기능 | 내용 |
|---|---|
| 홈 | 봉투를 물고 달리는 강아지, 서비스 지역과 등록된 쓰레기통 수 |
| 지도 | OpenStreetMap 지도, 내 위치, 서비스 지역(반경 1.5km) 표시, 종류별 쓰레기통 마커 |
| 추천 | 가장 적절한 1곳 + 대안 2곳. 거리에 "버릴 수 있을 가능성"을 반영한 체감 거리로 정렬 ([기준](docs/product.md#7-추천-기준-초안)) |
| 길찾기 | 카카오맵 도보 길찾기 링크 |
| 등록 | 사진 + 현재 GPS로 새 쓰레기통 등록, 바로 지도에 표시. 사진은 1200px로 줄이고 위치정보(EXIF) 제거 |
| 내 등록 삭제 | 로그인 없이, 등록한 휴대폰에서만 내가 등록한 쓰레기통 삭제 |
| 휴대폰 대응 | 카메라를 다녀와도 작성 중이던 등록 내용 유지, 카카오톡 안 브라우저 안내 |

아직 하지 않은 것: 상태 제보(없어졌어요 등), 현장조사 데이터 채우기, 정보 화면, PWA, QR 실사용 테스트 → [개발 단계](docs/development.md)

## 서비스 지역

**서울 구로구 항동 생활권**에서 시작합니다. 행정구역이 아니라 실제 산책 동선 기준입니다.

- 중심: 푸른수목원 / 범위: 도보 최대 20분 (직선 약 1.5km)
- 산책 동선: 푸른수목원, 항동 하버라인, 항동 철길, 서울수목원현대홈타운스위트, 역곡역 주변
- 확장 계획: **항동 → 구로구 → 서울시**

## 데이터 원칙

- 반려견 배변봉투를 버려도 되는지(`pet_waste_status`)는 현장 안내문, 관리기관 안내, 운영자 현장 확인 같은 근거가 있기 전까지 항상 `unknown`
- 일반 쓰레기통이라는 이유만으로, 이름이 '배변봉투함'이라는 이유만으로 "버려도 된다"고 판단하지 않음
- 사용자가 등록한 쓰레기통은 바로 보이지만, 배변봉투 가능 여부는 서버 규칙으로 항상 `unknown`
- 공용 공간의 쓰레기통만 등록 (예외: 현대홈타운스위트 단지 안 3곳, `단지 안` 표시)
- 모든 데이터는 출처(`source`, `coord_source` 등)를 추적할 수 있게 기록. 카카오 로컬 API 결과는 저장하지 않음

자세한 내용: [데이터 구조와 원칙](docs/data.md)

## 기술 스택

| 영역 | 기술 | 선택 이유 |
|---|---|---|
| 프론트엔드 | React + Vite + TypeScript | 자료가 많고 유지보수하기 쉬움 |
| 스타일 | Tailwind CSS | CSS 파일 관리 없이 빠르게 UI 구성 |
| 지도 | OpenStreetMap + Leaflet | 가입·API 키 없이 사용. 길찾기는 카카오맵 링크 |
| DB·사진 | Supabase (PostgreSQL + Storage) | 별도 서버 없이 DB·API. 접근 규칙은 [`supabase/setup.sql`](supabase/setup.sql) |
| 배포 | Vercel | `main`에 합치면 자동 배포 |
| 형태 | 모바일 웹 | 앱스토어 없이 링크·QR로 바로 사용 |

## 실행 방법

```bash
npm install
npm run dev
```

- 컴퓨터: 브라우저에서 `http://localhost:5173`
- 휴대폰: 컴퓨터와 같은 Wi-Fi에 연결한 뒤, 터미널에 나오는 `Network: http://192.168.x.x:5173` 주소로 접속
- 쓰레기통 등록을 쓰려면 `.env.example`을 복사해 `.env`를 만들고 Supabase 값을 넣습니다. 값이 없으면 등록 버튼이 숨겨지고 운영자 데이터만 보입니다.
- 개발 중(`npm run dev`)에는 지도를 눌러 좌표 확인·테스트 위치 지정을 할 수 있습니다. 배포 화면에는 나오지 않습니다.

API 키는 `.env` 파일에만 넣으며, 저장소에는 절대 커밋하지 않습니다.

## 폴더 구조

```
src/
├── pages/            Home(첫 화면), MapPage(지도)
├── components/       지도 위 카드·등록 화면, 마스코트, 아이콘
├── lib/              거리·방향 계산, 추천 순위, 사진 처리, 등록·삭제, 카카오톡 안 브라우저 대응
├── hooks/            내 위치, 쓰레기통 데이터
├── config/areas.ts   서비스 지역 (중심 좌표, 반경)
└── types/bin.ts      쓰레기통 데이터 형식
data/
├── bins/             운영자가 확인한 실제 쓰레기통
├── schema/           데이터 형식 정의 (JSON Schema)
└── mock/             UI 개발용 가짜 데이터 ([MOCK] 표시)
supabase/setup.sql    DB 표와 접근 규칙
```
