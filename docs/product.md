# 서비스 기획 — 쓰레개똥

> 개똥은 치웠는데, 어디다 버리지?

## 1. 한 줄 정의

산책 중 배변봉투를 든 보호자에게, 지금 위치에서 가장 가까운 **버릴 수 있을 가능성이 높은 쓰레기통**을 빠르게 보여주는 모바일 웹 지도 서비스.

## 2. 해결하려는 문제

- 산책 중 강아지가 배변하면 보호자는 봉투에 담는다. **그다음 버릴 곳을 찾기 어렵다.**
- 일반 지도 앱에서 '쓰레기통'은 검색 대상이 아니어서 잘 나오지 않는다.
- 쓰레기통이 있어도 **반려견 배변봉투를 버려도 되는지** 알 수 없다.
- 지자체에 따라 "사용한 봉투는 집으로 가져가세요"라고 안내하는 곳도 있다.
  → 그래서 이 서비스는 "버려도 된다"고 단정하지 않고, **확인된 정보와 확인되지 않은 정보를 구분해서** 보여준다.

## 3. 타깃 사용자와 사용 순간

| 항목 | 내용 |
|---|---|
| 누구 | 반려견과 산책하는 보호자 |
| 언제 | 배변을 봉투에 담은 직후 |
| 상태 | 한 손 사용, 급함, 화면을 오래 못 봄, 밤일 수 있음 |
| 원하는 것 | "어느 쪽으로 몇 분 걸어가면 되는지" 한눈에 |

## 4. 기존 지도 앱과의 차이

| 기존 지도 앱 | 쓰레개똥 |
|---|---|
| 쓰레기통 검색이 거의 안 됨 | 쓰레기통만 보여줌 |
| 배변봉투 투기 가능 여부 정보 없음 | `확인됨 / 금지 안내 있음 / 확인 안 됨`을 구분해 표시 |
| 검색어 입력 → 목록 → 선택 | 앱을 켜면 추천 후보가 바로 보임 |
| 실제 존재 여부 불명 | 현장조사 + 사용자 제보로 최신화 |

## 5. MVP 기능 범위

### 포함
1. 현재 위치 확인
2. 지도 표시
3. 주변 쓰레기통 마커 표시 (종류별로 시각적 구분)
4. 가장 적절한 후보 1곳 + 대안 2곳 표시
5. 쓰레기통 상세 정보 (장소 설명, 종류, 상태, 사진, 마지막 확인일)
6. 외부 지도 앱(카카오맵)으로 길찾기
7. 제보: 없어졌어요 / 위치가 달라요 / 배변봉투 가능 안내 있음 / 투기 금지 안내 있음 / 새 쓰레기통

### 제외 (MVP 이후 검토)
- 회원가입·로그인
- 커뮤니티, 강아지 프로필, 산책 기록
- 앱 내 길찾기 (외부 지도 앱이 더 잘함)
- 사용자 사진 업로드 제보
- 관리자 화면 (초기에는 Supabase 대시보드로 운영)

## 6. 핵심 사용자 흐름

```
앱 실행
  └─(첫 실행) 위치 권한 허용
지도 + 하단 추천 카드 자동 표시
  └─ [길찾기] 1탭 → 카카오맵 도보 길찾기
```

- 다른 후보를 원하면: 마커 탭 → 카드 변경 → [길찾기]
- 도착했는데 없으면: [없어졌어요] → 다음 후보 추천

## 7. 추천 기준 (초안)

거리만으로 정렬하지 않고, **'실제로 버릴 수 있을 가능성'**을 반영한 체감 거리로 정렬한다.

| 조건 | 가중치 (실제 거리 × ) |
|---|---|
| `pet_waste_status = allowed` | 1.0 |
| `bin_type = pet_bag_box` + `unknown` | 1.2 |
| 일반쓰레기 포함 + `unknown` | 1.3 |
| 재활용만 + `unknown` | 1.8 |
| `not_allowed` 또는 `status ≠ active` | 추천 제외 |

- 가중치는 현장 테스트 피드백으로 조정한다.
- `waste_kind`에 따른 우선순위는 **배변물 허용 여부가 아니라** 쓰레기 종류에 따른 후보 순서일 뿐이다.

## 8. 화면 구성 (초안 — UI/UX는 사용자가 직접 설계)

| 화면 | 형태 | 역할 |
|---|---|---|
| 지도(홈) | 메인 | 내 위치, 마커, 하단 추천 카드 |
| 상세 | 하단 시트 | 쓰레기통 정보, 길찾기, 제보 버튼 |
| 제보 | 하단 시트 | 상태 제보 / 새 쓰레기통 위치 지정 |
| 정보 | 시트 또는 페이지 | 서비스 소개, 데이터 출처, 피드백 링크 |

필요한 상태 화면: 로딩, 위치 권한 거부, 서비스 지역 밖, 주변 후보 없음, 네트워크 오류.

## 9. 서비스 지역과 확장 계획

- **1단계 (현재):** 항동 생활권 — 푸른수목원 중심 도보 20분(직선 약 1.5km)
  - 푸른수목원, 항동 하버라인 주변, 항동 철길, 서울수목원현대홈타운스위트 주변, 역곡역 주변
- **2단계:** 구로구 (서울시 가로쓰레기통 공공데이터 구로구분 활용 검토)
- **3단계:** 서울시

## 10. 실제 사용자 테스트 계획

- 아파트 게시판에 QR 2개 부착
  1. 앱 사용하기
  2. 사용 후 Google Form 피드백
- 피드백으로 쓰레기통 위치, 추천 기준, UX를 개선한 뒤 다음 지역으로 확장
- QR 주소는 인쇄 후 바뀌지 않도록 고정 주소를 사용한다.
