# 디자인 시스템 — 쓰레개똥

> 둥글고 따뜻하고 귀엽지만, **산책 중 한 손으로 빠르게 쓰는 도구**라는 점이 먼저다.
> 장식 때문에 기능이 묻히면 장식을 뺀다.

코드 위치: 토큰 `src/styles/index.css`, 마스코트 `src/components/mascot/Mascot.tsx`

---

## 1. 키워드

Cute · Round · Warm · Friendly · Simple · Hand-drawn · Soft colors

- 펫샵·유아용 앱처럼 보이지 않게: 원색, 무지개색, 과한 반짝이, 모든 곳에 캐릭터 금지
- 감각적인 일러스트 앱처럼: 넓은 여백, 크림 바탕, 적은 색 수, 큰 타이포

## 2. 색

| 토큰 | 값 | 용도 |
|---|---|---|
| `cream` | `#F7F1E5` | 기본 배경 |
| `cream-deep` | `#EFE4CF` | 배경 위 옅은 면 |
| `paper` | `#FFFDF8` | 카드, 버튼 위 글자 |
| `line` | `#E6DAC4` | 구분선 |
| `ink` | `#3F3429` | 본문·제목 (순수 검정 대신) |
| `ink-soft` | `#75665A` | 보조 문구 |
| `sage` / `sage-deep` | `#657A4E` / `#52643F` | **주요 행동 버튼** / 눌림 |
| `sage-light` | `#DDE5C9` | 일러스트 배경, 선택된 칩 |
| `orange` | `#D9824B` | 작은 포인트 (리드줄, 물음표, 주의) |
| `butter` / `butter-light` | `#E9B949` / `#F5E2AE` | 형광펜 강조, 포커스 링 |

**비율 (대략):** 크림 70% · 잉크 15% · 세이지 10% · 오렌지·버터 5% 이하

- 주요 버튼은 **세이지 하나로 통일**한다. 화면에서 가장 진한 색 면이 곧 "누를 곳"이다.
- 오렌지 위 흰 글자는 대비가 부족하다(약 2.9:1). 오렌지는 **면이 아닌 포인트**로만 쓴다.
- 세이지(`#657A4E`) 위 `paper` 글자는 약 4.6:1로 본문 대비 기준을 넘는다.

## 3. 글꼴

| 역할 | 글꼴 | 사용 |
|---|---|---|
| 디스플레이 | **Jua** (`font-display`) | 로고, 화면의 큰 문구 1개 |
| 본문·UI | **Pretendard** (`font-sans`) | 버튼, 설명, 정보 |

- Jua는 둥글고 친근하지만 많이 쓰면 유치해진다. **한 화면에 큰 문구 하나 + 로고**까지만.
- 크기: 큰 문구 38px / 버튼 18px bold / 본문 16px / 보조 14px. 산책 중이라 14px 미만은 쓰지 않는다.

## 4. 형태

| 요소 | 규칙 |
|---|---|
| 주요 버튼 | pill(`rounded-pill`), 높이 64px, 화면 아래쪽 엄지 영역 |
| 카드 | `rounded-card`(28px) |
| 하단 시트 | 위쪽 모서리만 28px |
| 아이콘 | 24px 기준, 선 2.2, 끝·꺾임 round (`components/icons/`) |
| 그림자 | `shadow-soft`, `shadow-button`만. 진하게 쓰지 않는다 |
| 터치 영역 | 최소 48×48px |

작은 요소(태그, 입력칸 안쪽)까지 모두 pill로 만들지 않는다. 큰 덩어리만 많이 둥글게.

## 5. 마스코트 강아지

이름은 아직 없다. 모든 화면에서 **같은 강아지 한 마리**만 쓴다.

### 생김새 (바꾸지 않는 것)

- **머리:** 거의 원형. 측면 포즈에선 머리 지름이 몸 높이보다 크다 (머리 큰 2등신 느낌)
- **귀:** 크고 늘어진 초코색 귀. 정면에선 양쪽, 측면에선 한쪽만
- **얼굴:** 점 눈(하이라이트 1개), 타원 코, 작은 w자 입, 볼터치. 눈썹·속눈썹·이빨 없음
- **몸:** 콩 모양, 등에 초코색 무늬 하나
- **다리:** 짧고 굵은 막대 4개, 끝이 둥글다. 발가락 표현 없음
- **꼬리:** 짧게 위로 말림
- **소품:** 오렌지 목줄. 배변봉투는 세이지색, 위가 묶인 모양

### 색 (`DOG` 상수)

| 부위 | 값 |
|---|---|
| 외곽선 | `#3F3429` (ink) |
| 몸·머리 | `#F8EAD0` |
| 뒤쪽 다리 | `#ECD8B4` |
| 주둥이 | `#FFF7E8` |
| 귀·무늬 | `#8A5A3B` (choco) |
| 볼·목줄 | `#D9824B`, 볼은 투명도 0.4 |
| 배변봉투 | `#9DB07C` |

### 선

- 외곽선 하나로 그린다. 측면 3px, 작은 얼굴(64px) 2.4px. 끝과 꺾임은 항상 round
- 명암·그라데이션 없이 단색 면만 쓴다
- `HandDrawnFilter`로 선을 살짝 흔들어 손그림 느낌을 낸다. 눈·볼·글자에는 쓰지 않는다 (또렷하게)

### 사용 규칙

- 캐릭터는 **보조 역할**이다. 버튼·정보보다 눈에 띄면 안 된다
- 한 화면에 한 번만 등장한다 (로고 얼굴 제외)
- 새 포즈는 `Mascot.tsx`에 컴포넌트로 추가하고 위 값을 그대로 쓴다

| 컴포넌트 | 쓰는 곳 |
|---|---|
| `MascotFace` | 로고, 빈 상태, 작은 안내 |
| `MascotWalkingWithBag` | 홈 메인 일러스트 |

앞으로 필요할 포즈(예정): 위치 권한 요청, 주변 후보 없음, 제보 완료

## 6. UX 원칙

- 한 손 사용: 주요 행동은 화면 아래쪽에, 버튼은 크게
- 텍스트는 짧게. 한 화면에 문장 2개 이하
- 화면은 스크롤 없이 한눈에 (360×640 작은 폰 기준 확인)
- 모바일 우선. 넓은 화면에서는 430px 폭 가운데 정렬
