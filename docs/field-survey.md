# 현장조사 계획

앱에 넣을 **실제 쓰레기통 위치**를 직접 산책하며 수집하는 계획.

## 1. 목표

| 단계 | 개수 | 시점 | 목적 |
|---|---|---|---|
| 1차 샘플 | 약 10곳 | 지금 (UI 개발과 병행) | 기록 방식 검증 (GPS 정확도, 기록하기 어려운 항목 확인) |
| 2차 확장 | 누적 20~30곳 | 현장 테스트(QR) 전 | 실제 사용자 테스트용 데이터 |

**전부 조사하고 시작할 필요는 없다.** UI 개발은 mock 데이터로 진행하고, 실제 데이터는 테스트 직전까지 채운다.

## 2. 조사 범위

- 중심: **푸른수목원**, 도보 최대 20분 (직선 약 1.5km)
- 우선 동선
  1. 항동 하버라인 주변
  2. 항동 철길
  3. 푸른수목원 (입구, 산책로)
  4. 서울수목원현대홈타운스위트 주변
  5. 역곡역 주변 (반경 경계 — 시간 여유가 있을 때)
- **조사 대상:** 공용 공간(길, 공원, 수목원, 철길, 정류장)의 쓰레기통, 반려견 배변봉투함
- **제외:** 아파트 단지 내부, 상가 내부, 사유지, 담배꽁초 전용 수거함

## 3. 준비물과 설정

- 휴대폰 카메라 **위치 정보 저장 켜기**
  - iPhone: 설정 → 개인정보 보호 및 보안 → 위치 서비스 → 카메라 → '앱을 사용하는 동안'
  - Android: 카메라 앱 설정 → 위치 태그 켜기
- 기록용 Google 스프레드시트 (아래 양식)

## 4. 촬영 방법 (1곳당)

1. **근접 사진** — 쓰레기통이 화면 가운데 오게
2. **주변 사진** — 위치를 알 수 있게 조금 떨어져서
3. **안내문 사진** — 배변봉투 관련 안내문이 있을 때만 (→ `pet_waste_status` 근거)

**주의:** 사람 얼굴, 차량 번호판, 아파트 동·호수 표시가 찍히지 않게 한다.

## 5. 기록 양식

| 열 | 입력 예시 | 대응 필드 |
|---|---|---|
| 조사번호 | SURVEY-001 | `source_ref` |
| 조사일 | 2026-10-12 | `source_date`, `last_verified_at` |
| 사진 파일명 | IMG_1234, IMG_1235 | `photo_url`, `coord_source=gps_photo` |
| 장소 설명 | 항동철길 입구 벤치 옆 | `detail_location` |
| 공용 공간 여부 | O | (X면 등록하지 않음) |
| 장소 유형 | 산책로 / 공원 / 도로변 / 정류장 / 기타 | `place_type` |
| 쓰레기통 종류 | 길거리 / 공원 / 배변봉투함 / 기타 | `bin_type` |
| 수거 종류 | 일반 / 재활용 / 일반+재활용 / 모름 | `waste_kind` |
| 배변봉투 안내문 | 없음 / 가능 안내 / 금지 안내 | `pet_waste_status` (없음 → `unknown`) |
| 봉투 비치 | 있음 / 없음 / 모름 | `bag_available` |
| 메모 | 저녁엔 자주 꽉 참 | `note` |

### `pet_waste_status` 판단 규칙

| 현장에서 본 것 | 입력 |
|---|---|
| 안내문 없음 | `unknown` |
| "반려견 배변봉투 버려도 됨" 류 안내문 + 사진 | `allowed` |
| "배변봉투 투기 금지", "집으로 가져가세요" 류 안내문 + 사진 | `not_allowed` |
| 일반 쓰레기통이라서 될 것 같음 | **`unknown`** (추측 금지) |

## 6. 조사 후 처리 (Claude가 담당)

1. 사진에서 GPS 좌표 추출
2. 지도 미리보기 생성 → 사용자가 위치 확인
3. 오차가 큰 곳은 수동 보정 (`coord_source = manual_pin`)
4. 사진 위치정보 제거·크기 축소 후 업로드 (Step 5 이후)
5. 양식 검증 → 데이터 변환 → 입력

**원본 사진과 원본 시트는 저장소에 올리지 않는다** (`data/raw/`는 `.gitignore` 처리됨).
